# Licences of the bundled assets

Every binary file under `wwwroot/assets` is listed here, with its origin and the
terms under which this site redistributes it. The repository `NOTICE` carries the
same list in summary.

A new asset needs an entry here, an entry in `NOTICE`, and a member of
`ShowcaseAssets`. Nothing under this directory is fetched from a third party at
runtime; every file is served from this site's own origin.

## Fonts

**`fonts/LiberationSans-Regular.ttf`**

Liberation Sans Regular, digitized data copyright 2010 Google Corporation and
copyright 2012 Red Hat, Inc. Licensed under the SIL Open Font License, version
1.1. The full text as shipped with the font is at `fonts/LICENSE.txt`.

The licence permits redistribution and embedding in a document. Embedding the
face in a generated PDF, which is what this site demonstrates, is the ordinary
use the licence contemplates. Note the reserved font names: a modified version
must not be distributed under the Liberation name, and this repository does not
modify the face.

## Colour profiles

**`icc/sRGB2014.icc`**

An ICC v2 sRGB profile published by the International Color Consortium, fetched
from the ICC profile registry. The ICC's own terms for profiles it owns permit
copying, distribution, embedding and sale without restriction. The full text as
published is at `icc/LICENSE.txt`.

## Images

**`images/testcard.png`, `images/testcard.jpg`, `images/testcard.bmp`,
`images/testcard.tif`**

Generated by `eng/generate-sample-images.py` in this repository, and therefore
covered by this repository's own licence. They are not photographs and carry no
third-party rights.

The four files are one image encoded four ways, so that a reader comparing
formats is comparing encoders rather than pictures. The design is a test card
rather than decoration: a smooth ramp shows the banding a reduced palette
imposes, hard edges show the ringing a lossy encoder introduces, saturated
blocks show colour quantisation, and a one-pixel checkerboard shows what
survives scaling.

Regenerate them with:

    python eng/generate-sample-images.py

The script is deterministic, so a rerun that changes a file indicates a change
to the script or to the encoder rather than noise.

NOTE: there is no GIF here, although the model accepts that format and the
library advertises it. VellumPdf.Layout 2.3.1 refuses ordinary GIF files with
"Invalid GIF LZW code", and only trivially compressible content decodes. The
sample is withheld rather than shipped in a state that cannot render.
